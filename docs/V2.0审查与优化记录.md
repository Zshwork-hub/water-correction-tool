# 水系订正工具 V2.0 审查与优化记录

更新时间：2026-07-02

## 本次审查目标

- 检查项目是否接近 V2.0 发布要求。
- 优先整理现有功能、界面和交互逻辑。
- 暂不急于重新打包 EXE，避免把打包问题和交互问题混在一起。

## 已完成优化

### 1. 项目状态保存

- `.waterproj` 项目版本号更新为 `2.0`。
- 项目保存/打开新增 `river_flow_mode`，可恢复“平滑/稳健”河道流向计算模式。
- 自动保存/恢复新增：
  - `river_flow_mode`
  - `confluence_inner_radius`
  - `confluence_outer_radius`

### 2. 界面结构整理

- 顶部工具栏由一长排按钮改为两行分组：
  - 文件与项目
  - 工作模式
  - 编辑记录
  - 视图
  - 会话
- 右侧面板按任务组织：
  - 文件状态
  - 编辑工具
  - 显示与配色
  - 流向辅助
  - 像元信息
  - 版本快照
- “矢量批量修正”移动到“编辑工具”区域，并与矢量容差放在一起。
- 网格、比例尺、流向箭头、原始对比、配色和预设移动到“显示与配色”区域。
- 流向预览/应用不再在顶部重复出现，集中到右侧“流向辅助”4 步流程中。

### 3. 交互逻辑整理

- “矢量批量修正”仅在订正河道模式可用。
- 流向方向下拉、应用方向、断点建议仅在订正流向模式可用。
- 流向辅助提示文案改为当前闭环流程：
  - 修好河道
  - 右键单点或拖框选择目标河道
  - 锁定选区河道
  - 设出口
  - 预览/应用河道流向
  - 预览/应用周边汇流
