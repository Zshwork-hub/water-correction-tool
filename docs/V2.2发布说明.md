# V2.2 发布说明

发布日期：2026-07-05

发布标签：`v2.2.0`

发布状态：本地打包与 smoke test 已通过，待 GitHub Release 上传。

发布文件：

- `水系订正工具_V2.2.0.exe`

## 版本定位

V2.2 是 V2.1.0 之后的一次维护稳定版本，不以新增大功能为主，而是重点提升项目可维护性、状态一致性、测试覆盖和发布可靠性。

本版本仍保持 V2.1 的核心工作流：先依据河流线 SHP 修正河道栅格，再锁定已订正河道作为骨架，预览并应用河道本体流向，最后辅助修正周边非河道像元流向。

## 主要变化

- 业务代码统一整理到 `water_tool/` 包目录，根目录保留启动脚本、配置、文档和测试。
- 拆分项目保存、打开、自动保存和恢复流程到 `water_project_workflow.py`。
- 拆分 UI 状态协调到 `water_ui_state.py`。
- 拆分流向辅助主流程到 `water_flow_workflow.py`。
- 拆分流向辅助状态提示到 `water_flow_status.py`。
- 新增 `water_state.py`，集中管理流向辅助状态清理和 `FlowPreviewState`。
- 新增 `water_flow_render.py`，承接流向辅助选区、锁定河道、出口和预览箭头绘制。
- 统一流向预览状态：预览数量、已一致数量、按钮文案、应用 tool/note 和应用提示均从 `FlowPreviewState` 读取。
- 修复恢复历史快照后撤销/重做无反应的问题。
- 加固项目数据重建：`.npz` 数组形状必须与 ASC 头信息一致，否则拒绝重建栅格。
- 增加轻量自动测试，覆盖历史快照、流向状态、预览状态和项目持久化。
