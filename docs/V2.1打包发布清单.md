# V2.1 打包发布清单

本文用于 V2.1 及后续版本发布前检查。目标是避免把功能回归、依赖问题、PyInstaller 打包问题和 GitHub Release 发布混在一起处理。

## 1. 发布前状态确认

发布前先确认：

- 本地工作流回归测试已完成，参考 `docs/V2.1工作流测试清单.md`。
- 当前稳定标签已创建并推送，例如 `v2.1.0`。
- `git status` 中不应有需要发布的未提交代码。
- `测试/`、`dist/`、`build/`、`user_data/`、业务数据文件不进入 Git。
- GitHub Release 只上传 EXE 等交付物，不把 EXE 直接提交到代码仓库。

当前 V2.1 已完成：

- 本地回归测试通过。
- `main` 已推送到 GitHub。
- `v2.1.0` 标签已推送到 GitHub。

## 5. PyInstaller 打包

当前打包配置文件：

```text
water_correction_tool_v2.spec
```

当前 spec 内 EXE 名称仍是：

```text
水系订正工具_V2.0_修复版
```

正式打 V2.1 前建议先二选一：

- 修改当前 spec 的 `name` 为 `水系订正工具_V2.1.0`。
- 或复制一份 `water_correction_tool_v2_1.spec`，在新 spec 中修改 `name`。

打包命令：

```powershell
python -m PyInstaller water_correction_tool_v2.spec --noconfirm --clean
```

如果新建了 V2.1 spec，则使用：

```powershell
python -m PyInstaller water_correction_tool_v2_1.spec --noconfirm --clean
```

## 6. NumPy/SciPy 常见打包问题

之前出现过：

- `No module named 'numpy._core._exceptions'`
- `No module named 'scipy._cyutility'`
- `scipy.linalg._cythonized_array_utils` 相关缺失

当前 `water_correction_tool_v2.spec` 已包含：

```python
collect_submodules("numpy")
collect_submodules("numpy._core")
collect_submodules("scipy.ndimage")
collect_submodules("pyproj")
"numpy._core._exceptions"
"scipy._cyutility"
"scipy.linalg._cythonized_array_utils"
collect_dynamic_libs("numpy")
collect_dynamic_libs("scipy")
collect_dynamic_libs("pyproj")
```

如果 EXE 仍提示缺模块：

1. 先记录完整错误堆栈。
2. 将缺失模块加入 spec 的 `hiddenimports`。
3. 如缺 DLL，检查是否需要加入 `collect_dynamic_libs(...)`。
4. 重新执行 `--clean` 打包。

不要在未确认缺失模块名称前盲目更换依赖版本。

## 7. EXE 验证

打包后优先验证 `dist` 中的 EXE。

建议检查：

- 双击 EXE 能打开主界面。
- 不依赖当前终端也能运行。
- 首次启动能选择工作目录。
- 能加载河道 ASC、流向 ASC、河流 SHP、汇流范围 SHP。
- 能执行一次河道画笔编辑和撤销。
- 能执行一次流向单点编辑和撤销。
- 能打开配色弹窗，修改透明度并恢复默认颜色。
- 能保存、加载、删除一个配色预设。
- 能保存项目、关闭程序、重新打开项目。
- 能导出河道 ASC 和流向 ASC。

如果 EXE 打开失败：

- 先用命令行运行 EXE，查看报错。
- 如 GUI 无错误窗口，可临时把 spec 中 `console=False` 改为 `console=True` 重新打包定位。
- 定位完成后再改回 `console=False`。

## 8. GitHub Release

GitHub Release 建议：

- Tag：`v2.1.0`
- Title：`水系订正工具 V2.1.0`
- Release notes：优先使用 `docs/V2.1发布说明.md`
- 附件：上传 V2.1 EXE，不上传业务数据。

Release 附件建议命名：

```text
水系订正工具_V2.1.0.exe
```

如未来需要提供压缩包，可命名：

```text
water-correction-tool-v2.1.0-windows.zip
```

压缩包内建议包含：

- EXE
- 使用说明
- 示例空项目说明或 README

不要包含：

- `*.asc`
- `*.shp` / `*.shx` / `*.dbf` / `*.prj`
- `.waterproj` / `.waterproj.npz`
- 用户本地日志和自动保存文件
