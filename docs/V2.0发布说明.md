# 水系订正工具 V2.0 发布说明

更新时间：2026-07-02

## 运行方式

双击运行：

- `dist\水系订正工具_V2.0_修复版.exe`

程序会在 EXE 所在目录下创建或使用 `user_data` 文件夹，用于保存自动保存、操作日志、配色预设和快捷键设置。

## V2.0 主要功能

- 河道 ASC 加载、显示、人工画笔/橡皮擦订正和导出。
- 流向 ASC 加载、显示、左键改方向、右键选中后应用方向和导出。
- SHP 参考线叠加显示，并支持矢量批量修正河道。
- 中键拖动、滚轮缩放、适配窗口、按当前缩放居中 SHP。
- 配色调整、配色预设保存/加载、网格、比例尺、流向箭头、原始对比。
- 撤销/重做、版本快照、自动保存与崩溃恢复。
- 画笔/橡皮擦快捷键设置，默认 `B` 为画笔、`E` 为橡皮擦。
- 操作模式提示区，显示当前模式、当前工具、锁定河道数量、预览类型和自动保存状态。

## 流向辅助工作流

推荐流程：

1. 在“订正河道”模式下，先用 SHP 批量修正河道，再人工补改。
2. 切换或加载流向 ASC 后，进入“订正流向”。
3. 右键单点或右键拖框选择目标河道。
4. 点击“锁定选区河道”。
5. 右键单点选择下游出口，点击“设为出口”。
6. 点击“预览河道流向”，确认后点击“应用河道流向”。
7. 点击“预览周边汇流”，确认后点击“应用周边汇流”。
8. 人工检查并补改少量问题像元。

## 项目保存与导出

保存项目用于继续编辑，不等同于最终成果导出。

保存项目会生成一组文件：

- `xxx.waterproj`
- `xxx.waterproj.npz`

`.waterproj` 保存路径、视图、工具、配色等项目配置；`.waterproj.npz` 保存当前编辑后的河道和流向栅格数组。移动项目时请两个文件一起移动。

导出 ASC 才是成果输出：

- 当前为“订正河道”模式时，导出当前河道栅格。
- 当前为“订正流向”模式时，导出当前流向栅格。

通常最终需要分别导出一次河道 ASC 和流向 ASC。

## 自动保存

- 自动保存间隔为 30 秒。
- 若“自动保存”勾选，关闭程序时会再保存一次当前会话。
- 自动保存用于防崩溃和误关，不建议替代正式项目保存。

## 已知说明

- 当前 EXE 约 111 MB。SciPy 打包时会间接收集部分 matplotlib/PyQt5 相关内容，后续如有需要可继续做体积瘦身。
- 首版 V2.0 曾漏收集 `scipy._cyutility`，修复版已在打包配置中显式加入该隐藏依赖。
- SHP 文件通常需要 `.shp`、`.shx`、`.dbf`、`.prj` 等配套文件，不要只复制单个 `.shp`。
- 若 Windows 安全策略拦截 EXE，请选择“仍要运行”或将程序加入信任目录。
