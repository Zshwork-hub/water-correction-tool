# 水系订正工具 V2.2 工作流测试清单

更新时间：2026-07-05

本文用于 V2.2 发布前后的手工回归测试。V2.2 是维护稳定版本，测试重点是确认 V2.1 主流程没有被代码拆分和状态统一影响。

## 1. 测试目标

- 确认河道订正、流向订正、项目保存和 ASC 导出主流程可用。
- 确认流向辅助预览、应用按钮文案和预览数量显示正确。
- 确认代码拆分后选区、锁定河道、出口和预览箭头显示正常。
- 确认项目保存/打开和自动保存恢复没有回退。

## 2. 测试数据

建议使用当前重庆测试数据：

- 河道 ASC：`Stream_origin.asc`
- 流向 ASC：`FDR.asc`
- 河流参考线 SHP：`重庆\重庆主要河流.shp`
- 汇流范围面 SHP：`重庆\重庆市.shp`

注意：SHP 需要 `.shp`、`.shx`、`.dbf`、`.prj` 等配套文件保持在同一目录。

## 3. 自动检查

发布前先运行：

```powershell
python -B -m unittest discover -s tests
python -B water_correction_tool.py --smoke-test
```

验收点：

- 单元测试全部通过。
- smoke test 无报错退出。
- 不出现 NumPy/SciPy/PyInstaller 依赖导入错误。

## 4. 启动与加载

1. 运行 `python water_correction_tool.py` 或 V2.2 EXE。
2. 选择或确认工作目录。
3. 加载河道 ASC。
4. 加载流向 ASC。
5. 加载河流 SHP。
6. 加载汇流范围 SHP。

验收点：

- 文件状态区显示四类文件路径。
- 河流 SHP 与汇流范围 SHP 均能显示。
- 范围 SHP 边界颜色和线宽可调。
- 放大、缩小、滚轮、中键拖动画布正常。

## 5. 河道订正流程

1. 切换到 `订正河道`。
2. 确认 `矢量容差` 默认值为 `0.2`。
3. 点击 `矢量批量修正`。
4. 使用画笔和橡皮擦局部补改。
5. 使用撤销/重做。
6. 创建版本快照并恢复。

验收点：

- 河道修改后窗口实时刷新。
- 快照恢复后窗口同步更新。
- 快照恢复后撤销/重做仍可用。
- 默认快捷键 `B` 画笔、`E` 橡皮擦可用。

## 6. 河道本体流向流程

1. 切换到 `订正流向`。
2. 确认橡皮擦被禁用。
3. 右键单点或右键拖框选择已订正河道。
4. 点击 `锁定选区河道`。
5. 右键选中锁定河道上的下游出口像元。
6. 点击 `设为出口`。
7. 点击 `预览河道流向`。
8. 检查预览箭头和状态提示。
9. 点击 `应用河道流向`。

验收点：

- 锁定河道显示正常。
- 出口标记显示正常。
- 橙色箭头表示应用后会修改的像元。
- 蓝色箭头表示符合预览条件但当前方向已一致的像元。
- 应用按钮文案为 `应用河道流向`。
- 应用后写入当前流向栅格，并自动创建流向快照。

## 7. 周边汇流：近远带模式

1. 在 `流向 -> 3 周边汇流` 中选择 `近远带`。
2. 确认默认近带为 `3`，远带为 `4`。
3. 点击 `预览周边汇流`。
4. 检查橙色和蓝色预览箭头。
5. 点击 `应用周边汇流`。

验收点：

- 只围绕已锁定河道局部区域生成预览。
- 不修改河道像元本身。
- 应用按钮文案为 `应用周边汇流`。
- 状态区显示需修改数量和已一致数量。

## 8. 周边汇流：范围SHP模式

1. 确认已加载汇流范围面 SHP。
2. 点击 `锁定范围内河道`。
3. 设置出口并完成河道流向预览/应用。
4. 在 `流向 -> 3 周边汇流` 中选择 `范围SHP`。
5. 设置 `最大距`，默认 `30`，`0` 表示不限距离。
6. 点击 `预览周边汇流`。
7. 检查预览后点击 `应用周边汇流`。

验收点：

- 只处理范围面内的非河道、非 NODATA 有效 FDR 像元。
- 最大距离过滤生效。
- 候选像元过大时会弹窗确认。
- 河道本体流向不会被周边汇流覆盖。

## 9. 项目保存与恢复

1. 保存项目为 `.waterproj`。
2. 关闭程序。
3. 重新启动程序。
4. 打开刚才保存的项目。

验收点：

- 河道、流向、河流 SHP、汇流范围 SHP 路径恢复。
- 编辑后的河道和流向数组恢复，而不是回到原始文件状态。
- 配色、辅助颜色、透明度、范围边界显示、范围线宽、汇流模式恢复。
- `.waterproj.npz` 缺失或损坏时，程序不会崩溃，应给出提示或回退到原始路径加载。

## 10. 自动保存恢复

1. 开启自动保存。
2. 进行少量河道或流向编辑。
3. 等待自动保存触发，或执行保存相关流程。
4. 模拟关闭后重新打开。
5. 尝试恢复自动保存。

验收点：

- 能恢复有效的河道/流向数组。
- 恢复后文件状态和模式状态正确。
- 恢复失败时不影响手动打开项目。

## 11. ASC 导出

1. 切换到 `订正河道`，导出河道 ASC。
2. 切换到 `订正流向`，导出流向 ASC。
3. 重新加载导出的 ASC 做简单检查。

验收点：

- 导出的 ASC 保留原始头信息。
- 河道导出和流向导出不会混淆。
- 导出文件能被程序重新加载。

## 12. 发布前结论

如果以上流程均通过，则 V2.2 可以发布为维护稳定版。

发布后新增功能应进入 V2.3，不再混入 V2.2。
