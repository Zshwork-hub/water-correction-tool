# 水系订正工具 V2.1 工作流测试清单

更新时间：2026-07-03

本文用于 V2.1 之后的手工回归测试。每次增加较大功能、重构 UI、修改流向辅助逻辑或准备打包前，优先按本文跑一遍核心流程。

## 1. 测试目标

- 确认河道订正、流向订正、项目保存和 ASC 导出主流程可用。
- 确认 V2.1 新增的汇流范围 SHP 加载、显示、锁定和范围汇流预览可用。
- 确认新增功能不会误改全国范围，不会覆盖已订正河道像元。
- 确认界面入口清晰，右侧分页交互可理解。

## 2. 测试数据

建议使用当前重庆测试数据：

- 河道 ASC：`Stream_origin.asc`
- 流向 ASC：`FDR.asc`
- 河流参考线 SHP：`重庆\重庆主要河流.shp`
- 汇流范围面 SHP：`重庆\重庆市.shp`

注意：SHP 需要 `.shp`、`.shx`、`.dbf`、`.prj` 等配套文件保持在同一目录。

## 3. 启动与加载

1. 运行 `python water_correction_tool.py`。
2. 选择或确认工作目录。
3. 点击顶部 `加载河道ASC`，加载河道栅格。
4. 点击顶部 `加载流向ASC`，加载流向栅格。
5. 点击顶部 `加载河流SHP`，加载河流参考线。
6. 点击顶部 `加载范围SHP`，加载汇流范围面。

验收点：

- 文件状态区显示四类文件路径。
- 河流 SHP 与汇流范围 SHP 均能显示。
- `显示` 页中 `矢量颜色` 和 `范围颜色` 可分别修改，二者不会互相覆盖。

## 4. 河道订正流程

1. 切换到 `订正河道`。
2. 确认 `编辑` 页中 `矢量容差` 默认值为 `0.2`。
3. 点击 `矢量批量修正`。
4. 用画笔和橡皮擦局部补改。
5. 使用撤销/重做确认编辑历史可用。
6. 创建版本快照，并在 `版本` 页恢复一次快照。

验收点：

- 河道修改后窗口实时刷新。
- 快照恢复后当前窗口同步更新。
- 画笔/橡皮擦快捷键可用，默认 `B` 为画笔、`E` 为橡皮擦。

## 5. 河道本体流向流程

1. 切换到 `订正流向`。
2. 在地图上右键单点或右键拖框选择已订正河道。
3. 点击 `锁定选区河道`，或在加载范围 SHP 后点击 `锁定范围内河道`。
4. 右键选中锁定河道上的下游出口像元。
5. 点击 `设为出口`。
6. 点击 `预览河道流向`。
7. 检查预览箭头后，点击 `应用河道流向`。

验收点：

- 锁定数量符合预期。
- 出口必须位于锁定河道内。
- 河道流向预览只作用于已锁定河道本体。
- 应用后写入当前流向栅格，并自动创建流向快照。

## 6. 周边汇流：近远带模式

1. 在 `流向 -> 3 周边汇流` 中选择 `近远带`。
2. 确认默认近带为 `3`，远带为 `4`。
3. 点击 `预览周边汇流`。
4. 检查橙色预览箭头。
5. 点击 `应用周边汇流`。

验收点：

- 只围绕已锁定河道局部区域生成预览。
- 不修改河道像元本身。
- 不扫描或修改全国范围。

## 7. 周边汇流：范围SHP模式

1. 确认已加载汇流范围面 SHP。
2. 点击 `锁定范围内河道`。
3. 设定出口并完成 `预览河道流向`、`应用河道流向`。
4. 在 `流向 -> 3 周边汇流` 中选择 `范围SHP`。
5. 点击 `预览周边汇流`。
6. 检查预览后点击 `应用周边汇流`。

验收点：

- 只处理汇流范围面内的非河道、非 NODATA 有效 FDR 像元。
- 面内像元默认向最近的已锁定河道骨架汇流。
- 面内候选像元数量过大时会先弹窗确认。
- 河道本体流向不会被周边汇流覆盖。

## 8. 项目保存与恢复

1. 点击顶部 `保存项目`，保存为 `.waterproj`。
2. 关闭程序。
3. 重新启动程序。
4. 点击顶部 `打开项目`，加载刚才保存的项目。

验收点：

- 河道、流向、河流 SHP、汇流范围 SHP 路径恢复。
- 配色、范围边界显示、范围线宽、汇流模式恢复。
- 当前编辑后的河道和流向数组恢复，而不是重新回到原始文件状态。

## 9. ASC 导出

1. 切换到 `订正河道`，点击 `导出ASC`，保存河道成果。
2. 切换到 `订正流向`，点击 `导出ASC`，保存流向成果。
3. 重新加载导出的 ASC 做简单检查。

验收点：

- 导出的 ASC 保留原始头信息。
- 河道导出和流向导出不会混淆。
- 导出文件能被程序重新加载。

## 10. 后续重点观察

- `范围SHP` 面很大时预览速度是否可接受。
- 是否需要新增最大汇流距离，避免远离河道的像元被强制汇入河道。
- 是否需要新增覆盖策略，如全部覆盖、只改异常、只改无效值。
- 多 polygon、多孔 polygon 暂未作为严格拓扑支持，遇到复杂面文件需谨慎判断。
